## 💻 Featured Projects

### 1. Smart Document Generator — ACM SVNIT

**Full-Stack Document Automation Platform**

- Developed a web application to automate official ACM SVNIT documents, including Executive Meeting Reports, Bill Certificates and Bill Summaries.
- Implemented automated PDF and DOCX generation using structured templates.
- Built role-based approval workflows for Author, Reviewer, Approver and Admin.
- Integrated NLP-powered quick-fill functionality to extract information from user prompts.
- Implemented authentication, document versioning and audit history.

**Tech:** React.js, Vite, Python, FastAPI, Pydantic, Firebase Authentication, PostgreSQL (Supabase), Resend API, ReportLab, python-docx.

🔗 [Live Application](https://smart-document-generator-acm-svnit.vercel.app/)
